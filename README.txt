# MemeGen AI 😂

MemeGen AI is a Python-based desktop application built using Tkinter
that helps users create memes based on real-life scenarios.

## Features

- Generate memes from user-described scenarios.
- Search for existing memes before generating a new one.
- Search for relevant memes using Google Images in a browser.
- Preview generated memes within the application.
- Save memes locally.
- Choose a humour style.
- Simple graphical user interface built with Tkinter.

## Tech Stack

- Python
- Tkinter
- Pillow
- Web Browser Integration

## Installation

1. Clone the repository:

   git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the project directory:

   cd MemeGen-AI

3. Install dependencies:

   pip install -r requirements.txt

4. Run the application:

   python main.py

## How It Works

1. Enter a scenario.
2. Search for an existing meme or generate a new one.
3. Alternatively, search for memes in your browser.
4. Preview and save the meme.
